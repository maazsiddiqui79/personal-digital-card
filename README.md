# Personal Digital Card

A modern digital identity and social links page built with React. It provides a simple and responsive way to showcase personal information, tech skills, and social profiles in one place.

## Live Demo

[https://maaz-social-card.vercel.app/](https://maaz-social-card.vercel.app/)

## Features

* Personal profile and introduction
* College and education information
* Tech stack showcase
* Social and professional links
* About section
* Contact information
* Portfolio and LinkedIn links
* Responsive design
* Modern dark UI
* Mobile-friendly layout
* Custom favicon and branding

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Clone the Repository

Using HTTPS:

```bash
git clone https://github.com/maazsiddiqui79/personal-digital-card.git
```

Using SSH:

```bash
git clone git@github.com:maazsiddiqui79/personal-digital-card.git
```

### Navigate to the Project

```bash
cd personal-digital-card
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```

## Build for Production

Create an optimized production build with:

```bash
npm run build
```

The production files will be generated in the `build` folder.

## Deployment

This project can be deployed easily using Vercel.

1. Clone or fork the repository.
2. Install the dependencies.
3. Push the project to GitHub.
4. Import the repository into Vercel.
5. Deploy the project.

Vercel will automatically build and deploy the React application.
